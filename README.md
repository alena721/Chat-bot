Консольный чат-бот, который позволяет разыграть диалог по заранее заготовленным вопросам.
Блягодаря нему можно:
- Добавлять, редактировать, удалять вопросы и ответы на них.
- Выводить все доступные вопросовы.
- Осуществлять ввод через файл (формат файла: первая строка текста - вопрос, следующая - ответ на вопрос).
- Разыгрывать диалог с гибкими возможностями ввода вопросов: 1. По номеру вопроса, 2. По тексту вопроса, пользователь может игнорировать заглавные буквы и знаки препинания.
